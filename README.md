# TerraPop

> 省 / 市 简称 · 省会 · 位置 —— 卡通中国地图上的一问一答记忆游戏。

一张卡通风格的中国地图，把「省全称 ↔ 简称 ↔ 省会 ↔ 地理位置」四者的对应关系
变成**一问一答**的快速记忆游戏。每答一题都就地揭示全部信息 + **双语百科与记忆点**，
连击越高分越高，答完自动进入下一题。

## 特性

- 🎨 **低调的地图，刺眼的高亮**：省份用极低饱和的暖灰调，整幅图接近单色纸感；
  「已知位置」时整幅地图压一层白纱、只把目标省挖空并叠上饱和金色 + 脉动光环——屏幕上只有一个亮点
- 🗺️ **卡通风中国地图**：34 个省级行政区（含港澳台）、南海诸岛插图框、港澳放大框、图例
- ⛰️ **有地貌的地图**：青藏/内蒙古/黄土/云贵高原、塔里木/准噶尔/柴达木/四川盆地、东北/华北/长江中下游平原、
  塔克拉玛干沙漠、东南丘陵，16 条山脉，9 条大江大河，13 个大湖
- 🕵️ **标注不剧透**：面状地貌只标类型名（高原 / 盆地 / 平原 / 沙漠 / 丘陵），绝不出现「四川盆地」；
  黑龙江、雅鲁藏布江、青海湖、滇池、秦岭 这类含省名或简称的名字会自动不标
- 🎛️ **正交完备的玩法矩阵**：已知 4 维度 × 要猜 3 维度 = **12 种组合**，再叠加
  **填空 / 三选一 / 四选一 / 五选一 / 定位** 5 种作答方式，任意组合都能玩
- 🧭 **四种模式**：随机一轮 / 邻接漫游（按地图接壤出题）/ 1 分钟极速 / 全答对为止（错题回队尾）
- 🔲 **范围自由组合**：大区 × 类型 两个维度多选，配 3 个快捷预设
- 📌 **位置固定**：作答区高度与屏幕坐标整局不变，选择题首个选项永远在同一处，提示行留位不跳动；
  上一题卡片压到 232px 不抢戏，题面 22px 加粗最显眼
- ⚡ **零阻断**：答完同一帧内上方卡片就换成上一题的信息与百科、下方同一位置换成下一题；
  没有揭示态、没有倒计时、没有弹窗、不需要点「继续」——连击就是这么来的
- ⌨️ **智能输入**：`sjz`→石家庄；**只有唯一命中且正确答案时才自动判定**，
  唯一但答错不会自动提交（回车才确认，方便改错）；多候选用 **↑↓ 选、回车提交**；
  繁简、行政后缀、别称（羊城、日光城）也认
- 🔦 **上一题卡片**：固定高度、内部滚动，展示上一题四维信息 + 判对判错 + 记忆点 + 双语百科；
  第一题时这里是玩法说明
- 🏁 **结算**：总分 / 答对 / 题量 / 正确率 / 最高连击 / 总耗时
- 🔊 **音效**：WebAudio 现场合成，答对琶音的音高随连击递升
- 🌏 **多语言**：中英界面，双语百科可切；架构支持继续扩展语言与国家
- 🎙️ **语音**：朗读题面与答案；语音作答已预留接口（stub）
- 📴 **完全离线**：零依赖、无构建、无后端，双击 `index.html` 即可运行

## 快速开始

```bash
git clone <this-repo>
cd TerraPop
open index.html          # macOS；或直接双击 index.html
```

不需要 `npm install`，不需要起服务器。

> 如果你更习惯本地 HTTP 服务：`python3 -m http.server` 后访问 `http://localhost:8000`
> （两种方式都支持，`file://` 直开是本项目的硬性目标）

## 在线版 / 部署

推到 `main` 会由 `.github/workflows/pages.yml` 自动校验并发布到 **GitHub Pages**
（首次需要在仓库 Settings → Pages 把 Source 选成 **GitHub Actions**）。

发布前会先跑 `scripts/selfcheck.mjs` 当闸门；浏览器端到端跑在 `ci.yml` 里当信号。
所有资源都是相对路径，放在 `https://<user>.github.io/<repo>/` 子路径下直接可用。
细节见 [`docs/deploy.md`](docs/deploy.md)。

## 怎么玩

模式 + 三个旋钮组合出玩法：

| 模式 | 说明 |
|---|---|
| 随机一轮（默认） | 范围内的省份随机排一轮，全部答完就结束 |
| 邻接漫游 | 按地图接壤一路挨着出题，像在地图上走一圈 |
| 1 分钟极速 | 60 秒内答得越多越好，时间到立刻结算 |
| 全答对为止 | 答错的题排到队尾再来一遍，直到每一省都答对 |

| 旋钮 | 可选 |
|---|---|
| 已知 | 全称 / 简称 / 省会 / 位置 / 随机 |
| 要猜 | 全称 / 简称 / 省会 / 位置 / 随机 |
| 作答方式 | 填空 / 三选一（简单）/ 四选一（普通）/ 五选一（困难）/ 定位 |
| 范围 | **大区 × 类型 多选自由组合** + 3 个快捷预设 |

每道题只问一处。上方固定高度的卡片永远是**上一题**的信息与百科（第一题时是玩法说明），
下方固定位置是**当前题**：已知信息 → 题面 → 作答区。答完不做任何等待，两边同时刷新——
位置固定、零阻断，所以能一路连着打。

填空时：拼音/首字母都行，**只有唯一命中且正确答案时才自动判定**；唯一但答错了不会自动提交，
按回车才确认，方便改。出现多个候选就用 **↑↓ 选、回车提交**。

## 重新生成地图数据

```bash
node scripts/build-map.mjs
```

输入数据随仓库提交在 `scripts/data/`，所以**离线也能复现**（已验证输出哈希一致）。
详见 [`scripts/README.md`](scripts/README.md)。

## 开发 / 自检

```bash
node scripts/selfcheck.mjs                     # 数据、地貌落点、拼音表、判定规则、玩法矩阵完备性
NODE_PATH="$(npm root -g)" node tests/e2e.mjs  # 浏览器端到端（需全局 playwright + 系统 Edge）
```

两个脚本都只依赖 Node 与已安装的全局 Playwright，**不是运行依赖**，`index.html` 本身依旧零依赖。
端到端跑完会把各步骤截图写到 `.tmp/shots/`。
