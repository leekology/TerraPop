## 地图边界数据

`maps/cn.js` 中的省界几何数据派生自：

- **DataV.GeoAtlas / 阿里云 DataV**
  <https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json>
  该服务转发的是**高德地图（Amap / AutoNavi）**的行政区划边界数据。

**这份数据不在 MIT 授权范围内**，其权利归原始提供方。用于个人学习、非商业展示一般无碍；
若要将本项目用于商业用途或再分发地图数据本身，请自行确认并获得相应授权。

生成过程记录在 `scripts/build-map.mjs`，可复现：脚本只做投影、抽稀、裁剪与格式转换，不引入额外几何。

## 行政区域与百科文本

`data/cn.js` 与 `data/cn.wiki.js` 中的行政区名称、简称、省会（首府）、
以及百科与记忆点文案，均为本项目**独立撰写的公开常识性描述**，不含从任何百科站点复制的段落。

## 第三方依赖

运行时**零依赖**：不加载任何 npm 包、CDN 资源或网络字体。
所有字体走系统字体栈，地图与图标全部是内联 SVG / CSS 绘制，因此可完整离线运行。

## 免责声明

本项目是**地理记忆辅助工具**，地图仅作示意：
- 省界经过抽稀简化，不具测绘精度；
- 位置判定为"大概对即可"的宽容判定；
- 全部地名与描述采用中立的地理/文化表述，不涉及任何领土、民族或历史争议主张。
