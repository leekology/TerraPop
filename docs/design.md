# 产品与交互设计

## 1. 信息来源与"正确答案"口径

四个信息维度：

| 维度 | key | 说明 |
|---|---|---|
| 全称 | `full` | 河北省 / 内蒙古自治区 / 香港特别行政区 |
| 简称 | `short` | 冀 / 内蒙古 / 沪·申（**可能多个**） |
| 省会 | `capital` | 石家庄；自治区称**首府**；直辖市与港澳**无省会** |
| 位置 | `location` | 地图上的多边形 |

必须提前统一的规则：

- **一省多简称**：四川=川/蜀、贵州=贵/黔、云南=云/滇、陕西=陕/秦、甘肃=甘/陇、上海=沪/申。填空时**全部接受**；选择题里它们是最好的干扰项（「蜀是哪个省？」）。
- **自治区是"首府"不是"省会"**：内蒙古/广西/西藏/宁夏/新疆。题面与揭示卡按类型显示正确措辞。
- **直辖市与特别行政区没有省会**：北京/天津/上海/重庆/香港/澳门。对这类地区，出题引擎**跳过 `capital` 维度**，避免出「北京市的省会是？」这种无意义题。揭示卡里显示「直辖市，市政府驻地即本市」/「特别行政区，不设省会」。
- **简称的英文形态**：简称本质是汉字，英文界面下用拼音（带声调）表达，如 冀 `jì` / 吉 `jí`。运行时会**同时接受**汉字、带调拼音、不带调拼音，所以「Hebei 的简称」和「Jilin 的简称」虽然都是 `Ji` 也不会误判。
- **易混淆知识点**（直接进 `facts`）：吉林省 ↔ 吉林市；河北省会变迁（保定 / 天津）；海南（省）↔ 海南州。

## 2. 玩法引擎：已知 1 个，猜其余

`known` 取 `full | short | capital | location` 之一，`ask` 是其余三者的任意子集。
预设玩法：

| 预设 | 已知 known | 要猜 ask | 定位 |
|---|---|---|---|
| 看位置猜省份（默认） | `location`（地图高亮该省） | full + short + capital | 主玩法，但位置是"送"的 |
| 看名称找位置 | `full` | location + short | 练定位 |
| 看省会找位置 | `capital` | location + short | 练定位 |
| 看简称找位置 | `short` | location + capital | 练简称-位置绑定 |
| 全都要 | 无（或随机给一个弱提示） | 其余全部 | 高难挑战 |

引擎在出题时按 `ask` 生成作答组件，`location` 永远走地图点击。

## 3. 单题流程

```
出题（地图高亮 / 题干卡片飞入）
   ↓
作答（点击地图 + 填空 / 选择）
   ↓
提交  ── 判定（每项独立判定，可部分得分）
   ↓
揭示卡（无论对错都全量揭示）
   ↓
下一题 → …… → 结算页
```

### 揭示卡内容（这是"加深记忆"的核心）

1. 地图：正确省高亮、省会红点脉动、从省会到省名标签的引线动画。
2. 四维信息翻牌：全称 / 简称（多简称并列）/ 省会（按类型显示"首府/无省会"）/ 位置。
3. **你的答案 vs 正确答案**逐项对照，错的用红色标注。
4. **双语百科**：`memo`（记忆点，把简称字源和省名串起来）+ `facts`（趣味知识点）+ `wiki`（百科段落）。
   - 语言设置：`跟随界面语言` / `始终双语并排`（默认，用于强化记忆）。
5. 语音朗读按钮（`speak()`）。

## 4. 判定与容错

**位置**（点击地图）：
- 命中正确省 → ✅ 满分
- 命中**相邻省**、或点击点距正确省质心在容差半径内 → 🟡「接近」，半分 + 提示
- 否则 → ❌

实现：点击→SVG 原生 `document.elementFromPoint` / `event.target` 拿到省份 path id，天然就是精确的多边形命中；"接近"用邻接表（预先从省界共享边算出）+ 质心距离兜底。设置里可切「宽松（接近算对）/ 严格」。

**填空**：
- 归一化：去首尾空格、去所有内部空格、全角转半角、繁转简（简繁映射表内置于 `data/`）、英文忽略大小写与重音符号。
- 全称：接受带后缀与不带后缀（河北 / 河北省 / Hebei / Hebei Province）。
- 简称：接受该省任一简称的汉字或拼音。
- 省会：接受标准名与 `capitalAliases`（呼市 / 羊城 / 日光城 …）。
- 简繁：至少覆盖港澳台与常见别名涉及的字符。

**选择题**：干扰项优先从**同一大区**或**易混淆项**里取，而非全库随机——让错误选项也有教学价值。

## 5. 难度旋钮（可独立切换）

| 旋钮 | 取值 |
|---|---|
| 范围 scope | 全部 34 / 单个大区（华北·东北·华东·华中·华南·西南·西北）/ 排除直辖市与港澳台 / 只含 23 省 |
| 提示 hint | 是否显示省会标记、简称首字、轮廓高亮、剩余尝试次数 |
| 干扰项 | 随机 / 同大区 / 易混淆优先 |
| 时间 | 无限 / 全局限时（60s 冲分）/ 每题倒计时 |
| 判定 | 宽松 / 严格 |

## 6. 视觉与地图设计

**风格**：中土 / 魔戒中土那种手绘古籍地图。米黄羊皮纸底纹（SVG 噪声 + 径向渐变），棕黑描边，装饰性罗盘、海怪、波浪纹、山形符号；标题用衬线/手写体。

**图层（由下到上）**：
1. 羊皮纸底 + 纹理
2. 海洋（边缘波浪纹装饰）
3. 地形装饰：山脉符号（三角簇）、沙丘点纹（塔克拉玛干）
4. 江河湖泊：蓝色手绘线 / 水塘
5. 省份多边形：淡色底 + 棕色描边（未作答时边界画成**淡色虚线**，弱化"国界感"）
6. 省会标记（可选显示）
7. 交互反馈：悬停微亮、选中描边、错误抖动、正确金光
8. 南海诸岛插图框（右下角，古典地图的 inset 画法）
9. 港澳放大插图（引出线 + 小框，解决点击目标过小）

**地形装饰坐标**：手工整理的经纬度折线（长江 / 黄河 / 珠江 / 黑龙江 / 松花江 + 青海湖 / 鄱阳 / 洞庭 / 太湖 / 洪泽 / 巢湖 / 呼伦湖 / 滇池 / 洱海 / 天池），
运行时用地图同一套投影参数换算，保证与省界严丝合缝。数据在 `data/cn.terrain.js`，不追求测绘精度，追求"一眼认得出"。

## 7. 移动端与可访问性

- 地图支持双指缩放与拖拽；点击目标最小 44px（港澳用放大插图框解决）。
- 键盘可完成全部操作（Tab 到地图可用方向键移动光标点，回车确认）。
- 配色对色盲友好：正确/错误除了红绿还配合图标与描边样式。
- 尊重 `prefers-reduced-motion`（关闭动效）。
