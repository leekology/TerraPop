# 产品与交互设计

> 本版把玩法从「一题答好几处」改成 **一问一答**：每道题只问一个维度，答完就地揭示、立刻进入下一题。
> 目标是「快速爽玩、盯着连击率」，不再有跳转输入和敲回车的摩擦。

## 1. 信息口径（"正确答案"的规则）

四个信息维度，贯穿整个产品：

| 维度 | key | 说明 |
|---|---|---|
| 全称 | `full` | 河北省 / 内蒙古自治区 / 香港特别行政区 |
| 简称 | `short` | 冀 / 内蒙古 / 沪·申（**可能多个**） |
| 省会 | `capital` | 石家庄；自治区称**首府**；直辖市与港澳**无省会** |
| 位置 | `location` | 地图上的多边形 |

必须统一的规则：

- **一省多简称**：四川=川/蜀、贵州=贵/黔、云南=云/滇、陕西=陕/秦、甘肃=甘/陇、上海=沪/申。全部可接受；选择题里它们是最好的干扰项。
- **自治区是"首府"不是"省会"**：内蒙古/广西/西藏/宁夏/新疆。题面与揭示按类型显示正确措辞。
- **直辖市与特别行政区没有省会**：北京/天津/上海/重庆/香港/澳门。凡是涉及 `capital` 的题目，这些地区直接从题源里剔除——不会出「北京市的省会是？」这种无意义题。
- **易混知识点**直接进 `facts`：吉林省 ↔ 吉林市；河北省会变迁（保定/天津）；海南（省）↔ 海南州。

## 2. 玩法矩阵：正交完备

一道题由三个互相独立的旋钮决定：

```
已知 known  ∈ { 全称, 简称, 省会, 位置, 随机 }        （4 个维度 + 随机）
要猜 asked  ∈ { 全称, 简称, 省会, 位置, 随机 }        （同上，且不能与 known 相同）
作答 style  ∈ { 填空, 三选一, 四选一, 五选一, 定位 }
```

- **12 种「已知 → 要猜」两两组合**全部可玩（4×3，含三个**纯文字**的互相猜，例如「已知简称 → 猜全称」）。
  早期版本每道题都含位置，这一版把纯文字组合补齐了。
- 每个组合都能叠加 4 种作答方式 → **48 种具体配置**；再加上范围与提示，组合空间是完整的。
- 当「要猜 = 位置」时作答方式**强制为定位**（位置只能点地图）——这就是第 5 种作答方式。
- `随机` 让已知/要猜在每道题上现抽，用来做无记忆点的纯练习。

**选择题难度**：不只是选项数量不同，干扰项的来源也不同：

| 作答方式 | 选项数 | 干扰项来源 | 得分权重 |
|---|---|---|---|
| 三选一 | 3 | 优先**跨大区**（一眼能排除） | ×0.7 |
| 四选一 | 4 | 混合 | ×0.8 |
| 五选一 | 5 | 优先**同大区**（最难） | ×0.9 |
| 填空 | — | — | ×1.0 |
| 定位 | — | — | ×1.0 |

## 3. 单题流程（一问一答）

```
出题：题面一行「已知『简称』，请说出它的『省会』」
      ↓
信息板 4 行：
   全称  ▸ ？（待揭晓）
   简称  ▸ 冀             ← 已知，直接显示
   省会  ▸ [ 输入框 / 选项 / 点地图 ]   ← 只有这一行要作答
   位置  ▸ ？（待揭晓）
      ↓
作答 → 立即判定
      ↓
就地揭示（不弹窗）：
   全称  ▸ ✓ 河北省
   简称  ▸ ✓ 冀
   省会  ▸ ✓ 石家庄   （错的会划掉你写的）
   位置  ▸ 地图上高亮 + 省会红点脉动 + 引线标注
   🧠 记忆点一行
      ↓
自动进入下一题（默认停留 1.6 秒，可调/可关；回车或点「下一题」可立即跳）
```

要点：

- **信息都在同一块板子上**：出题时只显示已知项，答完把四行补齐——「其余信息直接展示，不弹出」。
- **没有提交跳转**：选选项、点地图、打拼音都是「一步到位」。填空模式下输入到无歧义时**自动判定**，不用敲回车。
- **完整百科仍在**，但改成可选的「百科」按钮弹窗（中英对照 + 趣味知识），不打断节奏；开着弹窗时自动下一题会暂停。
- **连击**是主要正反馈：HUD 常驻显示连击 / 正确率 / 得分，正确答案的音效音高随连击递升。

## 4. 智能输入（类输入法）

作答文本时同时接受：**汉字、无声调拼音、拼音首字母、拉丁名、以及去掉行政后缀的写法**。

| 输入 | 结果 |
|---|---|
| `sjz` / `shijiazhuang` / `石家庄` | 石家庄（精确匹配） |
| `sj` | 石家庄 → **唯一，自动判对，不用回车** |
| `f` | 福建 → 唯一，自动判对 |
| `hn` | 河南 / 湖南 / 海南 → **给候选**，点一个即提交 |
| `hb` | 河北 / 湖北 → 给候选 |
| `石家` | 石家庄（前缀在提交时也算对） |
| `廣東省` | 广东（繁简折叠 + 去后缀） |
| `Hebei Province` | 河北（英文名、多词首字母 `hp` 都行） |
| `羊城` / `石头城` | 广州 / 南京（**别称只认完整输入**，不参与前缀匹配，免得抢别人的答案） |

实现要点（`js/game.js`）：
- `expand()` 把一个写法展开成「原文、去后缀、无声调拼音、首字母」几种可接受形式；汉字的拼音由 `data/han-initials.js`（148 字的查表）推导。
- 每个维度的输入分 **primary**（正式名称 / 简称 / 省会 / 拼音 / 首字母）与 **extra**（别称）两层。
  **前缀匹配只看 primary**，所以「sj」不会被「盛京」抢走；只有完整输入才会认别称。
- 判定规则与匹配规则一致：完全匹配 → 对；是某个正式写法的前缀 → 也对。

## 5. 位置判定与容错

- 精确命中：SVG 原生 hit-test 给出的省 id 与答案一致 → 满分。
- 「接近」：命中**相邻省**（运行时用省界共享边算出邻接表），或点击点距正确省质心在容差半径内 → 半分，并在地图上标出正确位置。
- 台湾、海南是岛屿没有陆上邻省，只能靠质心距离兜底。
- 设置里可切「宽松（相邻算接近）/ 严格」。

## 6. 难度旋钮

| 旋钮 | 取值 |
|---|---|
| 已知 / 要猜 / 作答方式 | 见第 2 节（正交矩阵） |
| 范围 | 全部 34 / 只含 23 个省 / 排除直辖市与港澳台 / 单个大区 |
| 提示 | 首字提示、显示所有省会标记、定位题提示所属大区 |
| 计时 | 不限时 / 全局 60 秒冲分 / 每题 20 秒 |
| 判定 | 宽松 / 严格 |
| 节奏 | 自动下一题开关 + 揭示停留时长（1 / 1.6 / 2.6 秒） |

## 7. 视觉：卡通、简洁、有地貌

- **风格**：扁平卡通。浅蓝海面 + 波浪纹，米白陆地 + 柔和投影，省份按大区上**七种柔和色**，
  省界是「白描边 + 深色细线」的双层画法，圆角卡片 + 圆体字栈 + 珊瑚橙主色。
- **地貌图层**（画在省份填色**之上**，半透明，保证既能看到大区配色又能看到地形）：
  - 高原（青藏/内蒙古/黄土/云贵）：暖米色 + 等高线斜纹
  - 盆地（塔里木/准噶尔/柴达木/四川）、平原（东北/华北/长江中下游）、丘陵（东南丘陵）：淡绿系
  - 沙漠（塔克拉玛干）：沙点纹理
  - 山脉（天山/昆仑/喜马拉雅/秦岭/大兴安岭/太行/横断/南岭/武夷… 16 条）：沿真实走向排列的山形符号
  - 河流（长江/黄河/珠江/黑龙江/松花江/淮河/澜沧江/雅鲁藏布江/塔里木河）：白色描边 + 亮蓝线芯
  - 湖泊（青海湖/鄱阳/洞庭/太湖/洪泽/巢湖/呼伦湖/滇池/洱海/纳木错/博斯腾/兴凯/长白山天池）
  - 地图左上角有**图例**，地貌名称直接标在图上（可关）
- **所有面状地貌都用一个 `clipPath` 裁在陆地轮廓内**，所以手绘的椭圆即使画大了一圈也绝不会溢到海里。
- 南海诸岛与九段线用右下角**插图框**（中文地图传统画法），港澳用**放大框**解决点击目标过小。

## 8. 音效

零素材，全部用 WebAudio 现场合成：

- 答对：三音符上行琶音，**音高随连击递升**（连击越高越兴奋）
- 接近：两个中性音
- 答错：下行锯齿音
- 结算：四音符收尾

## 9. 语音

- `speak()` 已实现：朗读题面与答案（Web Speech API，按语言选音色）。
- `listen()` 是 stub：作答入口已抽象为 `commit({kind, value|regionId})`，未来接语音识别只需在回调里转成同样的调用。

## 10. 移动端与可访问性

- 窄屏下地图与信息板纵向堆叠；地图支持双指缩放与拖拽。
- 选项带 `1-5` 数字快捷键；回车提交 / 进入下一题；Esc 关闭弹窗。
- 配色避免仅靠红绿区分：对错同时用 ✓ / ≈ / ✗ 图标与边框样式表达。
- 尊重 `prefers-reduced-motion`，并提供「动画」开关。
