# 多语言与多国家扩展指南

## 1. 设计原则

1. **语言是数据，不是代码分支。** 界面文案、地区名称、百科内容都以 `locale` 为 key 存放在 data 里，`i18n.js` 只负责查表与回退。
2. **地区数据与地图数据解耦。** `data/cn.js` 描述"是什么"，`maps/cn.js` 描述"在哪、长什么样"，二者只通过 `id` / `adcode` 关联。
3. **百科层单独一个文件。** 它是最需要持续增补、也最需要多语言翻译的部分，独立成 `*.wiki.js`，可分批交付。
4. **语言标签用 BCP-47 子集**：当前使用 `zh-Hans`、`en`。加繁体只需要再加 `zh-Hant`，无需改动任何逻辑。

## 2. 当前支持的语言

| 标签 | 文案文件 | 地区名 | 百科 |
|---|---|---|---|
| `zh-Hans` | `locales/zh-Hans.js` | `data/cn.js` | `data/cn.wiki.js` |
| `en` | `locales/en.js` | 同上 | 同上 |

回退顺序：`当前语言 → country.defaultLocale → 第一个可用语言`。

## 3. 双语揭示（记忆强化）

答完题的揭示卡会展示百科，语言策略由设置项 `wikiLocaleMode` 控制：

- `follow` —— 只显示当前界面语言。
- `bilingual`（**默认**）—— 当前语言 + 另一种语言并排，用于对照记忆。
- `alwaysOther` —— 只显示非当前语言（沉浸式外语学习）。

这样做的理由：把「省名 / 简称 / 省会」这类**母语知识**与**外语表达**放在一起出现，
一次作答同时强化两层记忆，也让界面天然具备外语学习价值。

## 4. 如何新增一种语言

1. 复制 `locales/zh-Hans.js` → `locales/xx.js`，翻译其中的字符串，保持 key 不变。
2. 在 `index.html` 里加一行 `<script src="locales/xx.js"></script>`（放在 `js/i18n.js` 之前）。
3. 在 `data/cn.js` 与 `data/cn.wiki.js` 中为每个条目的对象里补上 `"xx": "…"` 字段。
   —— 缺字段不会崩，`i18n.js` 会自动回退到 `defaultLocale`。
4. 若该语言需要简繁/变体折叠规则，在 `data/han-variants.js` 里补充映射。

## 5. 如何新增一个国家

以法国为例：

1. **地图**：`scripts/build-map.mjs` 是按国家参数化的生成器，新增一个输入数据与配置（bbox、投影参数、地区层次），产出 `maps/fr.js`，
   结构完全对齐 `TERRAPOP.maps.<id>` 的契约（`projection` / `regions` / `capitals`）。
2. **地区数据**：新建 `data/fr.js`，写入 `TERRAPOP.countries.fr = { id:"fr", names:{…}, mapId:"fr", regions:[…] }`。
   每个 region 必须含 `id / type / group / names / fullNames / short / capital / capitalTerm`。
   —— 不同国家的"四级信息"可能对不上，比如法国是 `région ↔ préfecture ↔ 缩写`，
   若某维度在目标国家不存在，把该项留空即可，引擎会自动跳过。
3. **百科**：新建 `data/fr.wiki.js`，写入 `TERRAPOP.wiki.fr`。
4. **入口**：`index.html` 里追加对应 `<script>`，并在 `js/app.js` 的国家选择器中加入新条目。
5. 无需改动 `game.js` / `map.js` —— 它们只依赖上述统一契约。

## 6. 需要留意的差异

| 问题 | 处理方式 |
|---|---|
| 某些国家没有"简称"概念 | `short` 可空；引擎跳过该维度（已在 `game.js` 中按"数据缺失即跳过"实现） |
| 罗马化规则不同 | 拼音放在数据里，不在代码里做转写 |
| 大小写 / 重音敏感性 | `normalize()` 统一去掉重音并小写；若某语言大小写有意义，用 `aliases` 显式补齐可接受写法 |
| 文字方向（RTL） | CSS 已使用逻辑属性（`margin-inline` 等）书写，加 RTL 语言时只需在 `<html>` 上加 `dir="rtl"` |
| 地名长度差异导致布局溢出 | 地区标签使用 `textLength` + `lengthAdjust`，长度自适应 |

## 7. 语音（stub 说明）

`js/voice.js` 暴露：

```js
TERRAPOP.voice = {
  available,                 // 浏览器是否支持 SpeechSynthesis
  speak(text, locale),       // 已实现：朗读题面 / 揭示卡
  listen({ locale, onResult, onError }),  // stub：语音识别作答，当前直接 onError('not-implemented')
  stop()
};
```

作答入口在 `app.js` 里已抽象为 `submitAnswer({ source, payload })`，
`source` 可取 `click | text | choice | voice`。
**未来接入语音识别只需让 `listen()` 回调里调用 `submitAnswer({source:'voice', …})`，其余逻辑无需改动。**
