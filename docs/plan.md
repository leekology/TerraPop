# TerraPop · 项目计划

> 一个「省市简称 / 省会 / 位置」在线竞猜记忆游戏。
> 第一版聚焦中国 34 个省级行政区，架构上支持多语言与扩展到其他国家。

## 一句话定位

用一张**手绘羊皮纸风格的中国地图**，把「省全称 ↔ 简称 ↔ 省会 ↔ 地理位置」四者的对应关系变成可玩的记忆游戏；
每答一题都给出**双语百科 + 记忆点**，把猜谜变成记忆加固。

## 已确认的产品决策

| 决策项 | 结论 |
|---|---|
| 地图视觉 | 中土羊皮纸手绘（米黄羊皮底 + 棕黑手绘描边 + 复古装饰） |
| 覆盖范围 | 34 个省级行政区全纳入（含港澳台、直辖市），特殊规则处理 |
| 交付形态 | 纯静态多文件，**双击 `file://` 能直接跑**，无构建、无后端、无框架 |
| 默认玩法 | 「点亮地图猜省份」——地图给位置，答全称 / 简称 / 省会 |
| 新增诉求 | 多语言（中/英起步）+ 其他国家可扩展 + 答完题展示附加双语百科 |

## 四条需求 → 设计映射

1. **简笔画中国地图，含地形与大江大湖**
   → 真实省界数据 + 手绘滤镜 → `maps/cn.js`；江河湖泊作为装饰图层 → `data/cn.terrain.js`。
   南海诸岛与九段线用**插图框**（中文地图传统画法）呈现，主图保持紧凑——这同时也是规避边界视觉争议的做法。

2. **竞猜模式：已知 全称 / 省会 / 简称 / 位置 之一，猜其它**
   → 抽象成 `known`（1 个）× `ask`（其余 3 个的子集）的通用引擎，预设 4 种常用组合。

3. **位置必须点击，其余填空或选择**
   → 答案维度分两类控件：`location` → 地图点击（带容差判定，相邻省算「接近」）；`full` / `short` / `capital` → 填空或选择题，可切换。

4. **答对/答错后揭示全部信息**
   → 统一的「揭示卡」：地图高亮 + 省会标记 + 划线动画 + 四维信息翻牌 + **双语百科 + 记忆点**。

## 功能清单（V1 范围）

- [x] 手绘风中国地图（34 省 + 港澳台 + 南海插图框 + 港澳放大框 + 江河湖泊 + 山脉装饰）
- [x] 地图缩放 / 平移（滚轮、拖拽、双指、按钮）
- [x] 5 种预设玩法，覆盖「已知全称 / 简称 / 省会 / 位置 之一，猜其余」的常用组合
- [x] 位置点选判定（正确 / 接近 / 错误 三档，宽松与严格可切）
- [x] 填空（含多简称、简繁、行政后缀、拼音与别称容错）与选择题两种作答方式
- [x] 揭示卡：四维信息对照 + 双语百科 + 记忆点
- [x] 计分、连击、结算页、中途退出
- [x] 难度旋钮：范围（全部 / 单大区 / 只含省 / 排除直辖市与港澳台）、提示、干扰项、计时
- [x] 中英界面切换；百科支持「跟随界面 / 双语并排 / 只看另一种语言」
- [x] 语音：`speak()` 朗读题面与揭示卡；`listen()` 语音作答留 stub
- [x] 自动化验收：`scripts/selfcheck.mjs`（数据与规则）+ `tests/e2e.mjs`（浏览器端到端）
- [ ] （V2）自定义「已知 / 要猜」任意组合、语音识别作答、错题本、每日挑战、其他国家地图

## 非目标（明确不做）

- 不做后端、不做账号系统、不做排行榜服务。
- 不做精确测绘级地图：地图是**记忆辅助工具**，位置判定「大概对即可」。
- 不在界面上出现任何领土、民族、历史争议性表述。
