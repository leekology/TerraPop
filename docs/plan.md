# TerraPop · 项目计划

> 一个「省市简称 / 省会 / 位置」在线竞猜记忆游戏。
> 第一版聚焦中国 34 个省级行政区，架构上支持多语言与扩展到其他国家。

## 一句话定位

用一张**卡通风格的中国地图**，把「省全称 ↔ 简称 ↔ 省会 ↔ 地理位置」四者的对应关系变成**一问一答**的快速记忆游戏；
每答一题都就地揭示全部信息 + **双语百科与记忆点**，并把连击数当作主要正反馈。

## 已确认的产品决策

| 决策项 | 结论 |
|---|---|
| 地图视觉 | 卡通扁平（浅蓝海面 + 米白陆地 + 大区柔和配色 + 图例），简洁但有地貌 |
| 覆盖范围 | 34 个省级行政区全纳入（含港澳台、直辖市），特殊规则处理 |
| 交付形态 | 纯静态多文件，**双击 `file://` 能直接跑**，无构建、无后端、无框架 |
| 玩法结构 | **一问一答**：每道题给 1 个已知维度，只答 1 个维度，其余就地展示 |
| 玩法矩阵 | 已知 4 × 要猜 3 = 12 种组合，全部可玩；再叠加 5 种作答方式，完全正交 |
| 作答方式 | 三选一 / 四选一 / 五选一 / 填空 / 定位（要猜位置时强制定位） |
| 输入 | 智能输入：汉字、拼音、拼音首字母；无歧义时自动判定，不用回车 |
| 多语言 | 中英起步；答完题展示双语百科，架构可扩展 |
| 音效 | WebAudio 现场合成，正确时音高随连击递升 |

## 四条原始需求 → 设计映射

1. **简笔画中国地图，含地形与大江大湖**
   → 真实省界数据 + 卡通风上色 → `maps/cn.js`；
   高原/盆地/平原/沙漠/丘陵/山脉/河流/湖泊共 60+ 个要素 → `data/cn.terrain.js`，
   叠加在省界之上并裁进陆地轮廓，既不溢到海里、也不会被省份填色盖住。
   南海诸岛与九段线用**插图框**（中文地图传统画法）呈现，港澳用放大框解决点击目标过小。

2. **竞猜模式：已知 全称 / 省会 / 简称 / 位置 之一，猜其它**
   → 抽象成 `已知 × 要猜` 的 12 种正交组合，含**三个纯文字组合**（例如「已知简称猜全称」），
   默认选题「看位置猜全称」。

3. **位置必须点击，其余填空或选择**
   → 答案控件由「作答维度 × 作答方式」决定：位置 → 点地图（容差判定，相邻省算「接近」）；
   其余 → 填空或三/四/五选一（干扰项难度随选项数递增）。

4. **答对/答错后揭示全部信息**
   → 一块信息板：作答前只显示已知项、其余「待揭晓」；作答后同一块板子补齐四行 + ✓/✗ + 记忆点，
   不弹窗、不跳页；完整双语百科作为可选详情。

## 功能清单（当前版本）

- [x] 卡通风地图（34 省 + 港澳台 + 南海插图框 + 港澳放大框 + 图例）
- [x] 地貌图层：13 个面状地貌 + 16 条山脉 + 9 条大江大河 + 13 个大湖
- [x] **四种模式**：随机一轮 / 邻接漫游（按地图接壤出题）/ 1 分钟极速（60 秒冲分）/ 全答对为止（错题回队尾）
- [x] **范围多选**：大区 × 类型 自由组合，另有 3 个快捷预设；选成 0 个会禁用开局
- [x] **低调的地图配色**：省份低饱和暖灰调、细浅省界、地貌半透明，整幅图接近单色纸感
- [x] **聚光灯高亮**：已知位置时整幅地图压白纱、只挖空目标省并叠饱和金色 + 脉动光环，一眼可见
- [x] **标注不泄露省份**：面状地貌只标类型名（高原/盆地/平原/沙漠/丘陵）；含省名或简称的山河湖名自动不标
- [x] 地图缩放 / 平移（滚轮、拖拽、双指、按钮）
- [x] 一问一答的玩法矩阵：12 组合 × 5 种作答方式，已知/要猜均可设为随机
- [x] **位置固定**：作答区固定高度与固定屏幕坐标，选择题首个选项永远在同一位置；提示行留位不跳动
- [x] **零阻断**：答完同一帧内上方卡片换成上一题信息、下方换下一题，没有揭示态 / 倒计时 / 弹窗 / 点「继续」
- [x] **上一题卡片**：固定高度 232px、内部滚动，展示上一题四维信息 + 判对判错 + 记忆点 + 双语百科；第一题显示玩法说明
- [x] **题目够显眼**：固定句式 12.5px 灰字 + 要答项 24px 加粗；作答区 200px 固定高度
- [x] **选项永不出滚动条**：固定两列网格，5 个选项 = 3 行，桌面 / 手机 / 横屏三档高度都算得出来
- [x] 结算页：总分 / 答对 / 题量 / 正确率 / 最高连击 / **总耗时**
- [x] **手机端紧凑模式**：断点 860px / 560px；整屏不滚动；`--vvh` 跟随软键盘；
      上一题压成一行摘要 + 底部抽屉；已知位置时地图自动放大；隐藏图例与长段说明
- [x] **触屏防误触**：轻点选省；按住 300ms（震动 + 描边提示）才能拖动；快速滑动作废；双指立即缩放
- [x] **横屏手机左右分栏**（844×390 下地图 456×328，上下堆叠会只剩 20px）
- [x] **触屏命中区放大**：每个省加 14px 透明描边（`non-scaling-stroke`），小省也点得准
- [x] **首次进入三步引导**（仅小屏，localStorage 记标记）
- [x] **定位题一键收范围**：首页提示行 + 7 个大区按钮，点一下 34 → 5
- [x] **高亮闪三下**（`tp-flash`）配合聚光灯抓视线
- [x] **地形元素合并**：每条山脉合成一个 path，元素 341 → 73
- [x] **题面分两级字号**：固定句式 12.5px 灰字，要答的那一项 24px 加粗
- [x] **智能输入**：汉字 / 拼音 / 拼音首字母；只在「唯一命中且正确」时自动判定，
      唯一但答错不自动提交（回车才确认）；多候选用 **↑↓ 选择、回车提交**
- [x] **显示即答案**：简称在所有语言下只显示汉字（`津`、`川 / 蜀`），注音只作讲解；
      把界面显示的写法原样抄进输入框（`津 (jīn)`、`川 / 蜀`）也一定判对
- [x] 位置点选判定（正确 / 接近 / 错误 三档，宽松与严格可切）
- [x] 常驻 HUD：得分 / 正确率 / 连击（连击 ≥3 高亮）
- [x] 音效：答对琶音（音高随连击递升）、接近、答错、结算
- [x] 中英界面切换
- [x] 语音：`speak()` 朗读题面与答案；`listen()` 语音作答留 stub
- [x] 左上角返回首页（进行中先确认，选「继续答题」会接上原计时）
- [x] 自动化验收：`scripts/selfcheck.mjs`（90 项）+ `tests/e2e.mjs`（15 节 / 36 种配置冒烟 + 模式与输入回归）
- [x] 部署：GitHub Pages 工作流 + CI
- [ ] （下一步）语音识别作答、错题本、每日挑战、其他国家地图

## 下一步建议（按性价比排序）

已完成：移动端三步引导、定位题一键收范围（放在首页，避免剧透）、触屏命中区放大、
横屏左右分栏、地形元素合并（341 → 73）、高亮闪动。

还没做：

1. **断点续玩**：把当前 session 存 localStorage，误关页面能接着打。
2. **无障碍**：题面/揭示内容接入屏幕阅读器（现在是手点朗读按钮）。
3. **连击强化**：3/5/10 连击时给屏幕边缘光晕与不同音效，正反馈更强。
4. **按缩放级别简化地貌**：现在是一次性全画，进一步可以在放大到某个级别后只保留局部。

## 非目标（明确不做）

- 不做后端、不做账号系统、不做排行榜服务。
- 不做精确测绘级地图：地图是**记忆辅助工具**，位置判定「大概对即可」。
- 不在界面上出现任何领土、民族、历史争议性表述。
